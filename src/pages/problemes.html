Ce qui pose problème pour quitter Framer

Les 17 pages sont recodées. Les numéros correspondent aux pastilles roses du site de test. Pour régénérer le site après une modification : node tools/build.js.

#1

Images hébergées chez Framer

Les 182 images sont maintenant dans le repo (src/static/assets/img, environ 32 Mo), réduites à 1600 px de large au maximum. Le build télécharge automatiquement celles qui manquent, plus aucune page ne dépend de framerusercontent.com.

Résolu
#2

La police Neue Montreal est payante

Le nom et « Product Designer » utilisent Neue Montreal (Pangram Pangram), servie par Framer. Hors de Framer, il te faut ta propre licence web, sinon une alternative gratuite. Le test utilise Inter Tight : c'est proche, mais un peu différent.

À décider
#3

Les cartes projets ne sont pas des liens sur le site actuel

Sur maxence.fyi, cliquer sur une carte ne mène nulle part. Dans le test, ce sont de vrais liens. Raising Studio est confirmé (même image que dans l'étude de cas). Les autres liens sont déduits des noms Framer. La carte « Set of logos redesign » (appelée « Carddi » dans Framer) mène à logoset. Sur visual, la carte du tableau mène à axeinos. Carddi, Sensia, Padel World et Interface design (appstore) ne sont liés depuis aucune page, comme sur le site actuel.

À confirmer
#4

La carte Micro-interactions est un composant animé Framer

La carte n'a pas d'image : c'est un composant Framer avec une animation. Le test le remplace par un point qui pulse en CSS. Pour retrouver l'animation exacte, il faut la recoder ou l'exporter en vidéo ou en GIF.

Mineur
#5

Page visual : deux cartes ont la même légende

Les deux cartes affichent « Set of logos redesign. », alors qu'elles mènent à Axeinos et à Quantum Pulse. C'est sûrement un oubli sur Framer, je les ai laissées telles quelles.

Contenu
#6

Le CMS de Photographs devient un fichier JSON

Les photos sont listées dans src/static/data/photos.json. Pour en ajouter une : déposer l'image dans assets/img, ajouter une ligne, lancer le build. La grille de photographs et la bande de photos du profil mobile se mettent à jour toutes les deux. Si tu veux une interface d'admin comme sur Framer, il faudra ajouter Decap CMS.

Fonctionne
#7

Photographs : les infos EXIF sont des valeurs de remplissage

Les 6 photos affichent exactement les mêmes réglages (ISO 50, ƒ1,5, 1/461 s), et la 02 a une faute (« 26m »). Je les ai reprises telles quelles. Les vraies valeurs pourraient être lues automatiquement depuis les fichiers.

Contenu
#8

About : le compteur « +0 years » du tennis

Le site actuel affiche « +0 years ». Soit l'animation de compteur est cassée, soit la valeur manque. Le test a un compteur animé qui fonctionne, il suffit de changer data-count-to dans src/pages/about.html.

Contenu
#9

Animations de about : recodées en CSS

Les accordéons, l'éventail d'images qui s'ouvre au survol, le défilement infini des affiches et le zoom sur les robots sont recodés sans librairie. Les courbes d'animation ne sont pas exactement celles de Framer : compare les deux côte à côte.

Fonctionne
#10

Microinteractions : les 7 démos sont recodées

Nested Pop-ups, Tabs Navigation, Tabs Preview, Classic Pop-ups, Open / Close Button, Badges Tooltip et Process Button sont recodées en HTML/CSS/JS sans librairie (src/static/js/micro.js), avec les tailles, couleurs, textes et images relevés sur Framer. Les courbes d'animation sont proches mais pas identiques. Sur mobile, les démos sont réduites pour tenir à l'écran.

Résolu
#11

Header et profil partagés entre les pages

Il y a maintenant un petit build sans dépendance (tools/build.js). Le header, le profil, le head et les scripts sont écrits une seule fois dans src/partials. Changer l'email, c'est modifier un seul fichier. Le site généré va dans test/, c'est ce dossier qui sera publié sur GitHub Pages.

Résolu
#12

Études de cas : générées, mais avec une mise en page simplifiée

Les 11 études de cas sont importées depuis le site actuel par tools/import-framer.py (titres, textes, images) et générées depuis un seul modèle. Différence avec Framer : les images de chaque section sont rangées dans une grille automatique (2, 3 ou 4 colonnes selon leur format), et non dans les compositions faites à la main. Le mur de logos qui défile sur logoset est recodé en CSS. Les sections Wireframing et Animations de Podz n'ont pas de visuel, déjà sur le site actuel.

À relire
#13

Version mobile

Les composants propres au mobile de Framer sont recodés : le bouton « + » qui se transforme en « × » et déplie product / visual / about en pastilles, et la bande de photos défilante du profil qui mène à Photographs. Sous 810 px, la photo de profil laisse sa place à la bande, comme sur Framer.

Résolu
#14

Statistiques de visites, pages oubliées et URLs

Les stats Framer (events.framer.com) disparaissent, à remplacer par GoatCounter, Umami ou rien. Le sitemap publie aussi /old-home, que je n'ai pas recodé. Les URLs restent identiques sur GitHub Pages : /about sert automatiquement about.html.
