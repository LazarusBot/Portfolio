Nested Pop-ups interact with me ! :)

Pop-up notifications appear as compact cards triggered by collaborator activity : a proposal, a comment, or a vocal message. Multiple alerts stack behind one another and collapse into a single summary, keeping the interface calm until the user chooses to look closer.

Clicking a tab starts a quick transition: the active indicator snaps across first, then the panel swaps in place. The same navigation also switches between profile pages, so each selected user feels like a fast, focused view change.

    Classic Pop-ups interact with me ! :)

    The notification is built as a reusable component: an avatar, a sender handle, an action label, and a secondary message line, all wrapped in a rounded card. It ships in both light and dark themes so it reads clearly across the whole app.

    Open / Close Button interact with me ! :)

    A single control toggles the notification between two states: collapsed into a small avatar badge, or expanded into a full card showing the sender, message, and a secondary line. Tapping the close icon shrinks it back down, keeping the interface tidy until the next alert needs attention.

    Badges Tooltip interact with me ! :)

    Hovering the avatar's badge opens a small tooltip listing alternate status icons, such as a warning, a favorite, and a highlight. Picking one instantly swaps the badge, giving each notification a quick, glanceable indicator without opening the card.
